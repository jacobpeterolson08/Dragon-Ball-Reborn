# Dragon Ball Reborn — Intro Test

Godot 4 prototype. Open `project.godot` with Godot 4, press F5 to run, and press **E**.

The project loads the sprite sheet already committed at the repository root: `Untitled 11-22-2026 03-06-34.png`. No renaming or moving is required.

The first eight 64×64 cells in the **top row** play in order at **0.1 seconds per frame** (10 FPS). Press E to restart; the eighth frame stays visible when the animation ends.
