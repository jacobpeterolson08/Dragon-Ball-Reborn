# Dragon Ball Reborn — Intro Test

Godot 4 prototype. Open `project.godot` with Godot 4, press F5 to run, and press **E**.

Put your 1024×1024 PNG at `assets/spritesheet.png`. The first eight 64×64 cells in the **top row** play in order at **0.1 seconds per frame** (10 FPS). Press E to restart; the eighth frame stays visible when the animation ends.

The sprite sheet itself is not included here yet. If you have already uploaded it elsewhere in this repository, copy it to `assets/spritesheet.png`.
