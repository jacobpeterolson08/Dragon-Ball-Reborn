# Dragon Ball Reborn — Intro Animation

Open `project.godot` with Godot 4 and press **F5** to run.

The project loads the committed sprite sheet `Untitled 11-22-2026 03-06-34.png` from the repository root.

Press **E** to play the first eight 64×64 sprites in the top row, in their original order: **1, 2, 3, 4, 5, 6, 7, 8**.

- All frames normally advance after **0.1 seconds**.
- **Sprite 4 is held for 0.3 seconds total** before advancing to sprite 5.
- Sprites are shown at **5× scale** (320×320 pixels), with nearest-neighbor filtering.
- Press **E** again to restart; sprite 8 remains visible when playback ends.

There is no speed slider or R/T alternative sequence.
