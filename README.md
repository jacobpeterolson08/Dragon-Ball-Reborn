# Dragon Ball Reborn — Intro Animation Comparison

Open `project.godot` with Godot 4 and press **F5** to run.

The project loads the committed sprite sheet `Untitled 11-22-2026 03-06-34.png` from the repository root.

Compare three sequences using the first eight 64×64 sprites in the top row:

- **E:** 1, 2, 3, 4, 5, 6, 7, 8 (original)
- **R:** 1, 2, 3, 4, 7, 5, 6, 8
- **T:** 1, 2, 3, 4, 5, 7, 6, 8

Each frame lasts 0.1 seconds (10 FPS). Press E, R, or T at any time to restart with that sequence. The final frame stays on screen.
