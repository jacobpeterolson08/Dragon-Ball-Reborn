# Dragon Ball Reborn — Intro Animation Comparison

Open `project.godot` with Godot 4 and press **F5** to run.

The project loads the currently committed sprite sheet `Untitled 11-22-2026 03-06-34.png` from the repository root.

The first eight 64×64 sprites in the top row are displayed at **5× scale** (320×320 pixels), using nearest-neighbor filtering.

- **E:** 1, 2, 3, 4, 5, 6, 7, 8 (original)
- **R:** 1, 2, 3, 4, 7, 5, 6, 8
- **T:** 1, 2, 3, 4, 5, 7, 6, 8

Use the **Frame delay** slider at the bottom of the game window to set the time between frames from **0.01 to 1.00 seconds**, in 0.01-second increments (default 0.10 seconds). You can adjust it while the animation is playing. Press E, R, or T to restart with that sequence; the final frame remains visible.
